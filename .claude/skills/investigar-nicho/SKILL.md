# Investigación de mercado

1. Llama al `investigador-mercado`. Pídele, según el pedido: (a) informe mensual de narrativa y nichos, (b) lote de 15-20 oportunidades para el canal activo, o (c) validación de un tema concreto.
2. Pasa el resultado al `verificador` (fuentes y fechas de cada cifra) y al `critico-retencion` (¿estas oportunidades generan videos en los que se haría clic?). Si encuentran problemas serios, devuélvelo al investigador una vez.
3. Guarda el informe en `sistema/investigacion/AAAA-MM-<tema>.md` (o la tabla de oportunidades en `canales/<canal>/oportunidades.md`), haz commit y resume en 5 líneas.

Si la API o la red fallan, dilo: el informe se marca "sin datos de API" y no se inventan cifras.
